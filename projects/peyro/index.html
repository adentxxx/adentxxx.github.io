PEYRO – История транзакций

Международный сервис для арбитража трафика оплаты зарубежных товаров и услуг.

#Fintech#B2C#Web & Mobile

Задача

Сделать историю транзакций удобнее и быстрее в работе.

Контекст

«История транзакций» нужна, чтобы следить за операциями по картам и счетам. Раздел пришлось пересобрать: фильтры и список операций было тяжело читать.

Выявленные проблемы

Тяжёлый монотонный список

• Нет группировки по датам, транзакции разных типов сливаются в одну ленту. • У операции не видно, с какой карты она прошла.

Нет единой структуры у фильтра

Поиск, выбор счёта и выбор команды стоят отдельно от табов с типами транзакций и селекта «Сформировать выписку».

Перегруженный CTA

Акцентная кнопка «Сформировать выписку» отвлекала от основной работы.

Лишний шаг для поиска

Поиск спрятан за кнопкой: чтобы ввести запрос, нужны два клика.

Неэффективная фильтрация

Три селекта заставляли по очереди открывать «Счёт», «Карту» и «Команду».

Принятые решения

Список транзакций

• Транзакции сгруппированы по датам, у дня есть заголовок. • Строки чередуют фон, список проще просматривать. • У операции есть иконка типа (пополнение, отказ, холд), номер и название карты.

Фильтры и кнопка выписки

Фильтры собраны в один блок и разделены чертой. • Сверху: период в календаре и тип транзакции в табах. «Сформировать выписку» переименована в «Скачать выписку» и стала outline, без акцентной заливки. • Снизу: один селект «Счёт / Команда / Карта» и поле поиска.

Встроенный поиск

Поле поиска по операциям всегда на экране, запрос вводится без лишнего клика.

Объединённый селект

Три фильтра собраны в один компонент: • Счета • Команды • Карты Если карт или команд много, вложенную группу можно свернуть, чтобы список не раздувался.

Результат

• В фильтре меньше лишних шагов. • Транзакции сгруппированы по датам и показывают больше данных. • Один селект по счетам, командам и картам сократил время и число кликов.
